# Reverse Number

This program reverses the digits of a given number.

## Features

* Takes a number from the user
* Extracts each digit
* Reverses the number
* Displays the reversed number

## Technology Used

* C

## Concepts Used

* Variables
* While loop
* Arithmetic operators
* Modulus operator

## Sample Output

```text
Enter a number: 12345
Reversed number: 54321
```
